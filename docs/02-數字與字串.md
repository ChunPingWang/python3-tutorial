# 第 2 章：數字與字串

> 🎬 **情境**
> 阿宏看了你昨天的成果，皺眉：「你印出來這樣我看不懂啊。給我一張**收據**——要有店名、品項、數量、單價、小計，還有含 5% 稅的總額。
> 對了，會員 9 折的金額要算到**整數**，不能出現 58.5 元這種東西，我找不開。」

這章要解決兩件事：**算得對**（數字）與**看得懂**（字串）。

## 2.1 😩 土法煉鋼：用加號黏字串

你目前只會第 1 章的工具：

```python
品項 = "珍珠奶茶"
數量 = 3
單價 = 65
小計 = 單價 * 數量

print("品項:" + 品項 + " 數量:" + str(數量) + " 小計:" + str(小計) + "元")
```

```
品項:珍珠奶茶 數量:3 小計:195元
```

能動，但問題一大堆：

1. **每個數字都要手動 `str()`**，忘記一個就 `TypeError`
2. **加號和引號多到數不清**，少一個引號整行爆炸
3. **看不出最後長什麼樣**，引號和 `+` 把版面切得稀爛
4. **對齊？別想了**。阿宏要的是一張整齊的收據，不是一行糊在一起的字

## 2.2 🧪 先寫測試

阿宏的需求寫成測試：

```python
# 🔴 這些函式還不存在,一定紅燈
assert 小計(單價=65, 數量=3) == 195
assert 含稅(195) == 205              # 195 * 1.05 = 204.75 → 阿宏要整數 205
```

> **TDD 的第一個好處就在這裡：它逼你在寫程式之前，先把模糊的需求問清楚。**

## 2.3 💡 數字運算

```python
7 + 3     # 10   加
7 - 3     # 4    減
7 * 3     # 21   乘
7 / 3     # 2.3333333333333335   除 → 結果永遠是 float!
7 // 3    # 2    整除,砍掉小數
7 % 3     # 1    取餘數
7 ** 3    # 343  次方
```

### ⚠️ `/` 一定給你 float

```python
print(10 / 2)        # 5.0  ← 不是 5!
print(type(10 / 2))  # <class 'float'>
```

這在 Python 3 是刻意設計的（Python 2 不是這樣，所以網路上舊文章會誤導你）。
**要整數結果就用 `//`。**

### `//` 和 `%` 的真實用途

阿宏問：「196 杯要幾個提袋？一袋裝 6 杯。」

```python
杯數 = 196
整袋 = 杯數 // 6      # 32 袋
剩下 = 杯數 % 6       # 4 杯
提袋數 = 整袋 + (1 if 剩下 else 0)   # 33 袋(最後 4 杯也要一個袋子)
```

`%` 還有一個超常見用途：**判斷奇偶、判斷整除**

```python
n % 2 == 0      # n 是偶數
n % 100 == 0    # n 是 100 的倍數
```

### 四捨五入：`round()`

```python
round(58.5)       # 58   ⚠️ 不是 59!
round(204.75)     # 205
round(204.75, 1)  # 204.8  第二個參數是小數位數
```

⚠️ **`round()` 的銀行家捨入（Banker's Rounding）**

Python 的 `round()` 遇到「正好 .5」時，會**進位到最接近的偶數**：

```python
round(0.5)   # 0
round(1.5)   # 2
round(2.5)   # 2   ← 不是 3!
round(3.5)   # 4
```

這不是 bug，是國際標準 IEEE 754 的規定，目的是讓大量數據平均後不會系統性偏高。
但這跟台灣人念書學的「逢五進一」不一樣，所以阿宏會覺得你算錯。

**要「逢五一律進位」請用 `decimal`：**

```python
from decimal import Decimal, ROUND_HALF_UP

def 四捨五入(數值) -> int:
    return int(Decimal(str(數值)).quantize(Decimal("1"), rounding=ROUND_HALF_UP))

四捨五入(58.5)    # 59  ✔ 符合阿宏的直覺
四捨五入(2.5)     # 3
```

### ⚠️ 浮點數的經典陷阱

```python
0.1 + 0.2 == 0.3      # False!!
print(0.1 + 0.2)      # 0.30000000000000004
```

這不是 Python 的 bug，是所有用二進位表示小數的語言共有的現象（JavaScript、Java、C 都一樣）。
就像十進位寫不出 1/3（0.3333…無限循環），二進位也寫不出 0.1。

**三個實務原則：**

| 場景 | 做法 |
| --- | --- |
| 比較浮點數 | 不要用 `==`，用 `math.isclose(a, b)` |
| **金額計算** | **用整數存「分」，或用 `decimal.Decimal`** |
| 顯示 | 用 f-string 格式化，`f"{x:.2f}"` |

```python
import math
math.isclose(0.1 + 0.2, 0.3)     # True ✔
```

> 🔍 **為什麼金融系統都用整數存分？**
> 因為 `1999` 這個整數永遠精準，而 `19.99` 這個浮點數不是。
> 阿宏的店金額都是整數元，我們用 `int` 就夠了；但如果你以後寫真正的金流系統，請記住這條。

## 2.4 💡 f-string：把值嵌進文字

Python 3.6 之後，字串格式化只需要記一件事：**在引號前面加 `f`，然後用 `{}` 包住變數。**

```python
品項 = "珍珠奶茶"
數量 = 3
單價 = 65

print(f"{品項} x{數量} = {單價 * 數量} 元")
# 珍珠奶茶 x3 = 195 元
```

對比一下：

```python
# 😩 舊寫法
"品項:" + 品項 + " 數量:" + str(數量) + " 小計:" + str(單價 * 數量) + "元"

# 🙂 f-string
f"品項:{品項} 數量:{數量} 小計:{單價 * 數量}元"
```

`{}` 裡面可以放**任何 Python 運算式**，而且**自動幫你轉字串**，不用 `str()`。

### 格式化語法：讓收據對齊

`{值:格式}`，冒號後面是格式規格：

| 寫法 | 結果 | 用途 |
| --- | --- | --- |
| `f"{3.14159:.2f}"` | `3.14` | 小數 2 位 |
| `f"{195:,}"` | `195`；`f"{1234567:,}"` → `1,234,567` | 千分位 |
| `f"{'珍奶':<10}"` | `珍奶········` | 靠左，寬度 10 |
| `f"{'珍奶':>10}"` | `········珍奶` | 靠右（金額用這個） |
| `f"{'收據':^20}"` | 置中 | 標題 |
| `f"{0.9:.0%}"` | `90%` | 百分比 |
| `f"{品項=}"` | `品項='珍珠奶茶'` | **除錯神器**，印出變數名和值 |

```python
print(f"{'品項':<12}{'數量':>4}{'小計':>8}")
print(f"{'珍珠奶茶':<12}{3:>4}{195:>8}")
print(f"{'冬瓜檸檬':<12}{2:>4}{90:>8}")
```

> ⚠️ **中文對齊會歪**：因為一個中文字在終端機佔兩格寬，但 Python 算它 1 個字元。
> 小專案忍耐一下即可；真的要完美對齊，用 `wcwidth` 套件或改用表格工具。第 13 章會提。

### `{品項=}` 除錯法

```python
單價 = 65
數量 = 3
print(f"{單價=}, {數量=}, {單價*數量=}")
# 單價=65, 數量=3, 單價*數量=195
```

不用再寫 `print("單價", 單價)`，Python 3.8+ 幫你連名字一起印。**強烈建議記住這招。**

## 2.5 字串的常用操作

阿宏的 LINE 訂單長這樣（真實世界的資料永遠是髒的）：

```python
原始 = "  珍珠奶茶 , 大杯 , 65  \n"
```

```python
原始.strip()                 # 去掉頭尾空白與換行 → "珍珠奶茶 , 大杯 , 65"
原始.replace(" ", "")        # 去掉所有空白
原始.split(",")              # 用逗號切開 → ['  珍珠奶茶 ', ' 大杯 ', ' 65  \n']
"珍珠奶茶".startswith("珍珠")  # True
"珍珠" in 原始                # True  ← 最常用的包含判斷
len("珍珠奶茶")               # 4
"-" * 30                     # 畫一條線!字串可以乘以數字
"、".join(["珍奶", "紅茶"])    # "珍奶、紅茶"  把清單接成字串
```

| 方法 | 做什麼 | 常用場景 |
| --- | --- | --- |
| `.strip()` | 去頭尾空白 | 清洗使用者輸入 **（幾乎每次都要）** |
| `.split(分隔符)` | 切成清單 | 解析 CSV、LINE 訊息 |
| `.join(清單)` | 接成字串 | 產生報表 |
| `.replace(舊, 新)` | 取代 | 清洗資料 |
| `.lower() / .upper()` | 大小寫 | 比對英文時先統一 |
| `in` | 包含嗎 | 搜尋 |
| `.startswith() / .endswith()` | 開頭/結尾 | 判斷檔名、前綴 |

### ⚠️ 字串是「不可變」的

```python
名稱 = "珍珠奶茶"
名稱.replace("珍珠", "椰果")
print(名稱)      # 還是「珍珠奶茶」!
```

`.replace()` 不會改動原字串，它**回傳一個新的**。要留住結果必須接起來：

```python
名稱 = 名稱.replace("珍珠", "椰果")    # ✔
```

> 🔍 這個性質叫 **immutable（不可變）**。`str`、`int`、`float`、`bool`、`tuple` 都是不可變的。
> 第 5 章你會遇到可變的 `list` 和 `dict`，到時候這個差別會變得非常重要。

### 多行字串與跳脫字元

```python
收據 = """================
   阿宏手搖飲
================"""

print("第一行\n第二行")      # \n 換行
print("欄位\t欄位")          # \t Tab
print("他說:\"好喝\"")       # \" 印出引號
print(r"C:\Users\新增")      # r 開頭 = 原始字串,\n 不會被當成換行
```

> ⚠️ 🪟 **Windows 路徑一定要用 `r"..."` 或 `/`**：
> `"C:\Users\new"` 裡的 `\n` 會被當成換行！這是 Windows 使用者最常見的災難。
> 第 9 章會教你更好的辦法：`pathlib`，從此不用自己處理路徑符號。

## 2.6 🟢 讓測試變綠：完成收據

```python
from decimal import Decimal, ROUND_HALF_UP

稅率 = 0.05
會員折扣 = 0.9

def 四捨五入(數值) -> int:
    return int(Decimal(str(數值)).quantize(Decimal("1"), rounding=ROUND_HALF_UP))

品項, 數量, 單價 = "珍珠奶茶", 3, 65
小計 = 單價 * 數量
含稅 = 四捨五入(小計 * (1 + 稅率))

收據 = f"""{'阿宏手搖飲':^20}
{'-' * 24}
{'品項':<10}{'數量':>4}{'小計':>8}
{品項:<10}{數量:>4}{小計:>8}
{'-' * 24}
{'含稅總計':<14}{含稅:>8}
"""
print(收據)

assert 小計 == 195
assert 含稅 == 205
assert 四捨五入(65 * 會員折扣) == 59
assert "珍珠奶茶" in 收據
print("🟢 全部通過")
```
