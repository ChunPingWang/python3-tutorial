# 第 5 章：資料結構 —— 一堆資料該怎麼擺

> 🎬 **情境**
> 阿宏：「我要完整的菜單，12 種飲料，每種都有中杯價和大杯價。還要庫存表。還有，今天賣出哪些『品項』——重複的算一種就好。」
>
> 你現在只會變數和清單。12 種飲料 × 2 種價格 = 24 個變數？

---

## 5.1 😩 土法煉鋼：變數爆炸

```python
珍奶中 = 55
珍奶大 = 65
冬瓜中 = 40
冬瓜大 = 45
紅茶中 = 30
紅茶大 = 35
# ...再 18 個
```

然後阿宏問：「客人說要『珍奶大杯』，多少錢？」

```python
客人要的 = "珍奶大"
價格 = ???       # 你沒辦法用一個字串去找到對應的變數
```

**這是關鍵時刻**：你手上有 24 個彼此獨立的變數，但你需要的是**「一張可以查的表」**。

---

## 5.2 Python 的四種基本容器

| 容器 | 長相 | 有順序 | 可修改 | 有重複 | 什麼時候用 |
| --- | --- | --- | --- | --- | --- |
| **list** 串列 | `[65, 45, 120]` | ✔ | ✔ | ✔ | 一串同類型的東西（今天的所有訂單） |
| **tuple** 元組 | `(25.03, 121.5)` | ✔ | ✖ | ✔ | 一組固定不變的值（座標、一筆資料的欄位） |
| **dict** 字典 | `{"珍奶": 65}` | ✔(3.7+) | ✔ | 鍵不重複 | **查表**（品名 → 價格） |
| **set** 集合 | `{"珍奶", "紅茶"}` | ✖ | ✔ | ✖ | **去重複**、判斷「有沒有」 |

> 🔍 **選哪一個？問自己兩個問題就好：**
> 1. 我要「一串」還是「一張對照表」？ → 串列 / 字典
> 2. 重複的東西要留著嗎？ → 要留用串列，不要留用集合

## 5.4 💡 list：一串東西

```python
訂單 = [65, 45, 120]

# 取值:索引從 0 開始
訂單[0]     # 65   第一個
訂單[-1]    # 120  最後一個(負數從後面數)
訂單[0:2]   # [65, 45]  切片:從 0 到 2(不含 2)

# 修改(list 是可變的)
訂單.append(90)        # 尾端加一個 → [65, 45, 120, 90]
訂單.insert(0, 30)     # 插到最前面
訂單.remove(45)        # 移除「值是 45」的第一個
訂單.pop()             # 取出並移除最後一個
訂單.sort()            # 就地排序(改變原清單!)
sorted(訂單)           # 回傳新的排序結果(不動原清單)
len(訂單)              # 長度
65 in 訂單             # 有沒有
```

⚠️ **索引從 0 開始，所以最後一個是 `len - 1`。** 寫 `訂單[len(訂單)]` 必得：

```
IndexError: list index out of range
```

⚠️ **`.sort()` 回傳 `None`！**

```python
結果 = 訂單.sort()     # 結果是 None,不是排序後的清單!
訂單.sort()           # ✔ 原清單已經被排好了
結果 = sorted(訂單)    # ✔ 要新清單用這個
```

這是初學者最常見的「為什麼我的清單變成 None」的原因。
**Python 的慣例：會改動原物件的方法，通常回傳 `None`。**

### ⚠️⚠️ 最重要的坑：清單是「共用」的

```python
a = [1, 2, 3]
b = a            # 這不是複製!b 和 a 是同一個清單的兩個名字
b.append(4)
print(a)         # [1, 2, 3, 4]  ← a 也被改了!
```

要真正複製：

```python
b = a.copy()      # 或 b = a[:] 或 b = list(a)
```

> 🔍 **為什麼會這樣？** 因為變數是「名牌」（第 1 章）。`b = a` 是把 `b` 這張名牌
> 貼到同一個清單上，而不是做一份新的。字串和數字不會有這問題，因為它們不可變。
> **凡是 list、dict、set 的指派，都要問自己一句：我是要同一個，還是要一份新的？**

### 串列推導式（list comprehension）

```python
# 😩 一般寫法
含稅清單 = []
for 金額 in 訂單:
    含稅清單.append(金額 * 1.05)

# 🙂 推導式:一行搞定
含稅清單 = [金額 * 1.05 for 金額 in 訂單]

# 加篩選
大額 = [金額 for 金額 in 訂單 if 金額 > 100]
```

讀法：**`[要什麼 for 每個東西 in 哪裡 if 條件]`**

⚠️ 不要寫超過一行看不懂的推導式。巢狀兩層以上就改回 `for` 迴圈，可讀性優先。

## 5.5 💡 dict：查表

這就是阿宏問題的答案。

```python
單價表 = {
    "珍珠奶茶": 65,
    "冬瓜檸檬": 45,
    "紅茶": 35,
}

單價表["珍珠奶茶"]        # 65     查表
單價表["椰果奶茶"] = 60   # 新增
單價表["紅茶"] = 38       # 修改(鍵已存在就是修改)
del 單價表["紅茶"]        # 刪除
"珍珠奶茶" in 單價表      # True   判斷鍵存不存在
len(單價表)              # 幾筆
```

### ⚠️ 查不到的鍵會爆炸

```python
單價表["綠茶"]
# KeyError: '綠茶'
```

**三種安全的查法：**

```python
單價表.get("綠茶")             # None(查不到不報錯)
單價表.get("綠茶", 0)          # 0   ← 指定預設值,最常用
if "綠茶" in 單價表: ...        # 先檢查再取
```

> 🔍 **什麼時候該用 `[]`，什麼時候用 `.get()`？**
> - 用 `[]`：這個鍵**一定要存在**，不存在就是程式有 bug，我要它立刻爆給我看。
> - 用 `.get()`：這個鍵**可能不存在**，那是正常情況，給個預設值就好。
>
> 別無腦一律用 `.get()`，那會把真正的 bug 藏起來，變成後面某處莫名其妙的 `None`。

### 走訪字典

```python
for 品名 in 單價表:                        # 只有鍵
    print(品名)

for 品名, 價格 in 單價表.items():          # 鍵和值 ← 最常用
    print(f"{品名}:{價格}")

單價表.keys()      # 所有鍵
單價表.values()    # 所有值
sum(單價表.values())   # 所有價格加總
```

### 巢狀字典：阿宏的完整菜單

```python
菜單 = {
    "珍珠奶茶": {"中杯": 55, "大杯": 65},
    "冬瓜檸檬": {"中杯": 40, "大杯": 45},
    "紅茶":     {"中杯": 30, "大杯": 35},
}

菜單["珍珠奶茶"]["大杯"]       # 65
```

🟢 **阿宏的問題解決了**：

```python
def 查價(品名, 杯型):
    return 菜單[品名][杯型]

查價("珍珠奶茶", "大杯")       # 65
```

24 個變數 → 一張表。而且新增品項只要多一行，不用改程式邏輯。

> 🔍 **字典為什麼快？**
> 字典用雜湊表（hash table）實作，查一筆的時間**和資料量無關**。
> 1 萬筆和 10 筆一樣快。用清單搜尋則要一筆一筆比對，1 萬筆就慢 1000 倍。
> **第 4 章說的「巢狀迴圈太慢」，解法通常就是先建一個字典。**

## 5.6 💡 set：去重複與集合運算

```python
今日訂單 = ["珍珠奶茶", "冬瓜檸檬", "珍珠奶茶", "紅茶"]

賣出品項 = set(今日訂單)      # {"珍珠奶茶", "冬瓜檸檬", "紅茶"}  重複自動消失
len(賣出品項)                # 3
```

集合運算（這是 set 最強的地方）：

```python
菜單品項 = {"珍珠奶茶", "冬瓜檸檬", "紅茶", "綠茶"}
今日賣出 = {"珍珠奶茶", "冬瓜檸檬", "紅茶"}

菜單品項 - 今日賣出      # {"綠茶"}      今天完全沒賣出的 ← 滯銷品!
菜單品項 & 今日賣出      # 交集:兩邊都有
菜單品項 | 今日賣出      # 聯集
```

一行就找出滯銷品，不用寫迴圈。

⚠️ **空集合要寫 `set()`，不是 `{}`**（`{}` 是空字典）。

## 5.7 💡 tuple：不可修改的一組值

```python
一筆訂單 = ("珍珠奶茶", "大杯", 65)
品名, 杯型, 價格 = 一筆訂單        # 拆包(unpacking)
```

tuple 和 list 幾乎一樣，差別只有**不能修改**。那為什麼要用它？

1. **表達「這組值不該被改」** —— 例如座標、資料庫的一筆紀錄
2. **可以當字典的鍵**（list 不行，因為會變的東西不能當鍵）
3. **函式回傳多個值時，Python 自動用 tuple**

```python
def 統計(訂單):
    return sum(訂單), max(訂單), len(訂單)      # 回傳一個 tuple

總額, 最大, 筆數 = 統計([65, 45, 120])          # 自動拆包
```

```python
# tuple 當字典的鍵:記錄每個(品項, 杯型)組合賣了幾杯
銷量 = {
    ("珍珠奶茶", "大杯"): 32,
    ("珍珠奶茶", "中杯"): 18,
}
```

## 5.8 🟢 讓測試變綠 + 統計熱銷

```python
from collections import Counter

菜單 = {
    "珍珠奶茶": {"中杯": 55, "大杯": 65},
    "冬瓜檸檬": {"中杯": 40, "大杯": 45},
    "紅茶":     {"中杯": 30, "大杯": 35},
}

def 查價(品名, 杯型):
    return 菜單[品名][杯型]

def 品項數量(菜單):
    return len(菜單)

def 賣出品項(訂單):
    return set(訂單)

def 熱銷品項(訂單):
    return Counter(訂單).most_common(1)[0][0]
```

`Counter` 是標準庫送你的計數器（第 12 章詳談）：

```python
Counter(["珍奶", "紅茶", "珍奶"])          # Counter({'珍奶': 2, '紅茶': 1})
Counter(今日訂單).most_common(3)           # 前三名
```

手寫版本長這樣（理解原理用）：

```python
次數 = {}
for 品項 in 今日訂單:
    次數[品項] = 次數.get(品項, 0) + 1      # ← .get 預設值的經典用法
```
