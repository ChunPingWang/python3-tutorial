## 12.2 `datetime`：日期與時間

```python
from datetime import date, datetime, timedelta

今天 = date.today()                  # date(2026, 9, 20)
現在 = datetime.now()                # 含時分秒

今天.year, 今天.month, 今天.day      # 2026 9 20
今天.weekday()                       # 0=週一 ... 6=週日
今天.isoweekday()                    # 1=週一 ... 7=週日
```

### 加減日期：`timedelta`

```python
昨天 = 今天 - timedelta(days=1)
上週同一天 = 今天 - timedelta(weeks=1)
三十天後 = 今天 + timedelta(days=30)

差距 = date(2026, 9, 30) - date(2026, 9, 1)
差距.days          # 29
```

**不要自己算月底有幾天、不要自己判斷閏年。** `timedelta` 全部處理好了。

### 格式化與解析

```python
今天.isoformat()                      # '2026-09-20'  ← 存檔一律用這個
今天.strftime("%Y年%m月%d日")          # '2026年09月20日'  給人看
date.fromisoformat("2026-09-20")      # 從字串轉回 date
datetime.strptime("2026/09/20", "%Y/%m/%d")   # 自訂格式解析
```

| 格式碼 | 意思 |
| --- | --- |
| `%Y` `%m` `%d` | 年(4位) 月 日 |
| `%H` `%M` `%S` | 時 分 秒 |
| `%A` `%a` | 星期全名 / 縮寫 |
| `%B` `%b` | 月份全名 / 縮寫 |

⚠️ **strftime 的輸出會受系統語系影響**（`%A` 在不同機器可能是 `Sunday` 或 `週日`）。
要跨平台一致，**自己做對照表**：

```python
星期名 = ["週一", "週二", "週三", "週四", "週五", "週六", "週日"]
星期名[今天.weekday()]
```

### ⚠️ 測試和日期：最容易出事的組合

```python
def 是週末():
    return date.today().weekday() >= 5      # ✖ 無法測試!
```

這個函式的結果取決於「今天是星期幾」，所以你的測試**週一到週五會過，週六日會失敗**。

**解法：把「現在幾點」當成參數傳進去。**

```python
def 是週末(某天: date) -> bool:              # ✔ 可測試
    return 某天.weekday() >= 5

# 測試
assert 是週末(date(2026, 9, 19)) is True     # 週六
assert 是週末(date(2026, 9, 21)) is False    # 週一
```

> 🔍 **這是 TDD 帶來的重要設計原則：把「不可控的東西」變成參數。**
> 時間、亂數、檔案、網路，都是不可控的。
> 一旦把它們變成參數，你的函式就從「有時候會壞的」變成「永遠可預測的」。

## 12.3 `json`：巢狀資料存檔

第 9 章講過。這裡補充三個實務重點：

```python
import json

# 1. 中文一定要 ensure_ascii=False
json.dumps({"品項": "珍奶"}, ensure_ascii=False)    # {"品項": "珍奶"}
json.dumps({"品項": "珍奶"})                        # {"品項": "珍奶"}

# 2. 排序鍵,讓 git diff 乾淨
json.dumps(資料, ensure_ascii=False, indent=2, sort_keys=True)

# 3. JSON 不認識 date、set、Decimal
json.dumps({"日期": date.today()})
# TypeError: Object of type date is not JSON serializable
```

⚠️ **第 3 點很常踩**。解法是先轉成字串：

```python
json.dumps({"日期": date.today().isoformat()})       # ✔
json.dumps({"品項": list(品項集合)})                  # set 要轉成 list
```

## 12.4 `collections`：`Counter` 與 `defaultdict`

### `Counter`：算次數的神器

```python
from collections import Counter

訂單 = ["珍奶", "紅茶", "珍奶", "冬瓜", "珍奶", "紅茶"]

計數 = Counter(訂單)
# Counter({'珍奶': 3, '紅茶': 2, '冬瓜': 1})

計數["珍奶"]                 # 3
計數["綠茶"]                 # 0 ← 不存在也不會 KeyError!
計數.most_common(3)          # [('珍奶', 3), ('紅茶', 2), ('冬瓜', 1)]
計數.total()                 # 6（3.10+）
```

手寫版要 4 行，`Counter` 一行。而且 `most_common()` 直接給你排行榜。

### `defaultdict`：自動產生預設值

```python
from collections import defaultdict

# 😩 一般字典
每日營收 = {}
for 日期, 金額 in 訂單資料:
    if 日期 not in 每日營收:
        每日營收[日期] = []
    每日營收[日期].append(金額)

# 🙂 defaultdict
每日營收 = defaultdict(list)          # 查不到的鍵自動變成 []
for 日期, 金額 in 訂單資料:
    每日營收[日期].append(金額)
```

```python
defaultdict(int)     # 預設 0   → 累加用
defaultdict(list)    # 預設 []  → 分組用
defaultdict(set)     # 預設 set()
```

⚠️ **`defaultdict` 的副作用**：光是「查詢」一個不存在的鍵，就會把它建立起來。

```python
d = defaultdict(int)
print(d["不存在"])      # 0
print(d)               # defaultdict(<class 'int'>, {'不存在': 0}) ← 被建立了!
```

要純查詢用 `.get()`，或改用普通 dict。

## 12.5 `statistics`：正確的統計

```python
import statistics as st

客單價 = [65, 45, 55, 65, 500]      # 最後那筆是團購

st.mean(客單價)       # 146  ← 被團購拉高了,不能代表一般客人
st.median(客單價)     # 65   ← 中位數,比較真實
st.mode(客單價)       # 65   眾數
st.stdev(客單價)      # 標準差
```

> 🔍 **為什麼阿宏要中位數？**
> 平均數會被極端值拉走。五個客人裡有一個團購 500 元，平均就變成 146，
> 但實際上根本沒人花 146。**中位數（把數字排好，取中間那個）不受極端值影響。**
>
> 判斷準則：**資料有極端值就看中位數，分布平均就看平均數。**

⚠️ `statistics` 的函式遇到空清單會拋 `StatisticsError`，記得處理：

```python
def 安全中位數(資料):
    return st.median(資料) if 資料 else 0
```

## 12.6 `re`：正規表示式（清洗資料）

阿宏的客人電話欄位長這樣：

```
"0912345678"  "0912-345-678"  "(02)2345-6789"  "+886912345678"  "0912 345 678"
```

你要統一成 `0912345678`。

```python
import re

def 清洗電話(原始: str) -> str:
    數字 = re.sub(r"\D", "", 原始)          # 把所有「非數字」換成空字串
    if 數字.startswith("886"):
        數字 = "0" + 數字[3:]
    return 數字
```

### 最常用的五個函式

```python
re.sub(樣式, 取代, 字串)      # 取代 ← 清洗資料最常用
re.search(樣式, 字串)         # 找第一個,回傳 Match 或 None
re.findall(樣式, 字串)        # 找全部,回傳 list
re.match(樣式, 字串)          # 從「開頭」比對
re.fullmatch(樣式, 字串)      # 整個字串完全符合 ← 驗證格式用這個
```

### 最常用的樣式

| 樣式 | 意思 |
| --- | --- |
| `\d` `\D` | 數字 / 非數字 |
| `\w` `\W` | 字母數字底線 / 其他 |
| `\s` `\S` | 空白 / 非空白 |
| `.` | 任何字元 |
| `*` `+` `?` | 0 次以上 / 1 次以上 / 0 或 1 次 |
| `{n}` `{n,m}` | 剛好 n 次 / n 到 m 次 |
| `^` `$` | 開頭 / 結尾 |
| `[abc]` `[^abc]` | 其中一個 / 不是其中任一 |
| `(...)` | 群組，可以用 `.group(1)` 取出 |

```python
# 驗證手機格式
re.fullmatch(r"09\d{8}", "0912345678")      # 符合
re.fullmatch(r"09\d{8}", "0912-345-678")    # None

# 抓出訂單編號裡的日期
m = re.search(r"(\d{4})(\d{2})(\d{2})", "ORD-20260920-001")
m.group(1), m.group(2), m.group(3)          # ('2026', '09', '20')
```

⚠️ **一律用 `r"..."` 原始字串寫樣式**，否則 `\d` 這種反斜線會被 Python 先吃掉一層。

> ⚠️ **不要用 re 做所有事。**
> 解析 HTML 用 HTML 解析器、解析 CSV 用 `csv` 模組、解析 JSON 用 `json`。
> re 適合的是「格式簡單且固定的文字」。
> 有句名言：「你用正規表示式解決了一個問題，現在你有兩個問題了。」

### 🧪 測試 re：一定要用參數化

正規表示式是最容易寫錯的東西，**每個規則都要有測試**：

```python
@pytest.mark.parametrize("原始,期望", [
    ("0912345678", "0912345678"),
    ("0912-345-678", "0912345678"),
    ("(02)2345-6789", "0223456789"),
    ("+886912345678", "0912345678"),
    ("0912 345 678", "0912345678"),
    ("", ""),                              # 邊界
])
def test_清洗電話(原始, 期望):
    assert 清洗電話(原始) == 期望
```

## 12.7 `itertools`：組合與分組

```python
from itertools import product, groupby, chain, islice

# 所有組合(菜單 × 杯型 × 甜度)
list(product(["珍奶", "紅茶"], ["中杯", "大杯"]))
# [('珍奶','中杯'), ('珍奶','大杯'), ('紅茶','中杯'), ('紅茶','大杯')]

# 把多個清單串起來
list(chain([1, 2], [3, 4]))          # [1, 2, 3, 4]

# 只取前 N 個(適合超大資料)
list(islice(range(1000000), 5))      # [0, 1, 2, 3, 4]
```

⚠️ **`groupby` 有個大坑：它只會把「相鄰」的相同元素分在一起**，
所以**一定要先排序**：

```python
資料 = sorted(訂單, key=lambda x: x["品項"])       # 先排序!
for 品項, 群組 in groupby(資料, key=lambda x: x["品項"]):
    print(品項, list(群組))
```

實務上，**分組用 `defaultdict(list)` 通常比 `groupby` 好懂**。

## 12.8 `random`：亂數（以及怎麼測試它）

```python
import random

random.randint(1, 10)              # 1~10 的整數(含 10)
random.choice(["珍奶", "紅茶"])     # 隨機選一個
random.sample(清單, 3)             # 不重複抽 3 個
random.shuffle(清單)               # 就地洗牌(回傳 None!)
```

### ⚠️ 亂數讓測試無法重現 —— 兩個解法

**解法一：固定種子**

```python
random.seed(42)
random.randint(1, 100)      # 每次都是同一個數字
```

**解法二（更好）：把亂數來源變成參數**

```python
def 抽獎(名單, 抽幾個, rng=random):     # 預設用全域 random
    return rng.sample(名單, 抽幾個)

# 測試時給它一個固定種子的產生器
def test_抽獎():
    rng = random.Random(42)              # 獨立的、可重現的產生器
    assert 抽獎(["A", "B", "C"], 2, rng=rng) == ["B", "A"]
```

> 🔍 **和 12.2 的日期問題是同一個道理：把不可控的東西變成參數。**
> 這個技巧叫「依賴注入」（dependency injection），聽起來很高級，
> 但你看到了，它其實只是「多一個參數」而已。
> **TDD 會自然而然把你推向這種設計。**

### `enum`：取代字串常數

```python
from enum import Enum

class 杯型(Enum):
    中杯 = "中杯"
    大杯 = "大杯"

# ✖ 用字串:打錯字不會報錯
訂單.杯型 = "大盃"          # 錯字,程式繼續跑

# ✔ 用 Enum:打錯立刻爆
訂單.杯型 = 杯型.大盃        # AttributeError!
```

### `functools.lru_cache`：一行加上快取

```python
from functools import lru_cache

@lru_cache(maxsize=128)
def 很慢的查詢(品項):
    ...        # 同樣的參數只會真的執行一次,之後直接回傳結果
```

⚠️ 只能用在**純函式**上（同樣輸入永遠同樣輸出）。
如果函式會讀檔案或資料庫，加了快取就會拿到過期的資料。
